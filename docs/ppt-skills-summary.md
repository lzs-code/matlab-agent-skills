### tencent-pptx 的实际工作方式(值得了解)

它不是"模型直接画 PPT",而是有一套工程链路:

```
项目目录/
├── DESIGN.md      # 视觉设计文档
├── STORY.md       # 内容叙事文档
├── assets/        # 静态资源
├── slides/        # 每页一个 .slide 文件(SlideDSL 源文件)
└── <名称>.pptx    # 最终产物
```

底层引擎 `slidep`(腾讯 `@tencent/slidep`)**本机已装好**,在 node 托管环境里:
- `slidep create <file>` — 建空白 PPTX
- `slidep upsert-dsl <file> --dsl-file <path>` — 插入/替换页
- `slidep lint <file> --dsl-file <path>` — **校验语法与文字溢出**

所以它是「模型写 DSL → 引擎渲染成 pptx → lint 校验溢出」,质量有工程保障。

## 三、怎么选(一句话版)

- **要一份能直接交付的 `.pptx`** → `tencent-pptx`(已装,直接说)
- **要求视觉质感、接受网页演示** → `guizang-ppt-skill`
- **想要一个技能通吃所有 PPT 场景** → `ppt-generator` v3
- **手上只有图片/PDF,要变成能改的 PPT** → `image-to-editable-ppt`
- **PPT 内容没问题就是难看** → `ppt-beautify`
- **学术汇报** → 你已装的 `literature-deep-reading` 出大纲,再交给 `tencent-pptx` 排版
- **先看视觉方向再定稿** → 用 `ardot-slides` 出设计稿

## 四、DeepSeek 能做 PPT 吗

### 能,而且这件事跟"模型是谁"关系不大

关键在于**分工**:

| 环节 | 谁负责 |
|------|--------|
| 内容策划、叙事结构、写文案 | **模型**(DeepSeek 完全胜任) |
| 写 SlideDSL / 调 `slidep` 命令 | **模型** |
| 渲染成 pptx、字体嵌入、文字溢出检测 | **`slidep` 引擎**(跟模型无关) |

**格式质量由引擎决定,内容质量由模型决定。** 换模型不会让 PPT 变丑或变好看多少,只会让文案和结构变好或变差。

而 DeepSeek 在内容侧本来是强项——中文表达、结构化输出、写代码。写 SlideDSL 和调命令行都属于它的舒适区。

### 本机实测结论

- `@tencent/slidep` **已安装在 node 托管环境**,`slidep` 命令可直接调用 → **PPT 生成链路是通的**
- 托管 Python 里**没有** `python-pptx`,但走 `tencent-pptx` 的链路不需要它

### 唯一的限制:配图

DeepSeek 是**纯文本模型,不自带生图能力**。所以 skill 里那些"AI 配图"功能需要单独调图像生成工具来完成(本机有图像生成能力和可灵连接器)。

这不是障碍,只是链路多一环:**DeepSeek 想文案和版式 → 生图工具出配图 → 引擎合成 pptx**。

### 一个现成的证据

**你现在这轮对话跑的就是 DeepSeek-V4.1-Flash。** 我刚刚做的事——读技能源码、扫本机环境、查市场接口、写这份汇总——全都是它在驱动。同一套能力用来驱动 PPT skill 没有任何区别。
